# WeChat Article Knowledge Base

一个面向微信公众号文章的本地知识库工具，支持扫码登录、批量抓取、账号级全量与增量同步，以及适合 AI 使用的分层索引。

## Description

A local knowledge base tool for WeChat public account articles. It supports QR-code login, batch article fetching, account-level full and incremental sync, and AI-friendly layered indexing, helping turn article archives into structured local data for search, reading, and downstream AI workflows.

## Features

- QR-code login for WeChat public account workflow
- Batch fetching and export of public account articles
- Account-level full sync and incremental sync
- Local structured storage for article archives
- AI-friendly layered indexing for downstream search and analysis
